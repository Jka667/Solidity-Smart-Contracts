# Solidity Smart Contracts

ERC-20 tokens, staking, token swap and registry contracts in Solidity 0.8.

**Skills:** Solidity, ERC-20, access control, reward logic

**Value:** Understanding of Web3 risks such as access control flaws and approval abuse.

Open a contract in [Remix IDE](https://remix.ethereum.org) to compile and deploy it.

> Learning project, not audited. Do not deploy to mainnet with real funds.
